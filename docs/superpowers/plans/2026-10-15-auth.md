# Users & Authentication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **This project runs in mentor mode:** the human writes the code; the mentor explains, reviews, and only writes files when a step says so. Steps are still written as concrete, verifiable actions.

**Goal:** Add user accounts and token authentication to the Ragnest API: signup, login, and a `GET /users/me` endpoint backed by a reusable `get_current_user` dependency.

**Architecture:** One `users` table (UUID pk, unique lowercased email, argon2 password hash). A new `app/modules/` layer holds two feature modules — `users` (model + read schema + `/users/me`) and `auth` (signup/login routers, schemas, service, security helpers, and the auth dependency). Both routers are mounted under a `/api/v1` prefix from the existing aggregate router.

**Tech Stack:** Python 3.13, FastAPI, Pydantic v2 (+ `email-validator`), SQLAlchemy 2.0 async, Alembic, `pwdlib[argon2]`, `PyJWT`, pytest + httpx/aiosqlite (in-memory SQLite).

**Spec:** `docs/superpowers/specs/2026-10-15-auth-design.md`

## Global Constraints

- Python 3.13, `uv`, single top-level `app/` package — **no `src/` layout**.
- Domain features live in `app/modules/<feature>/`; each owns its router, schemas, models, service.
- Reuse `app/db/base.py` — `Base` (naming convention) and `TimestampMixin` (`created_at`, `updated_at`).
- Must behave identically on **SQLite (tests)** and **Postgres/Neon (dev)** — use SQLAlchemy generic types (`Uuid`, string-backed enum), never Postgres-only types (`citext`).
- Any DB engine must use `settings.database_url` + `settings.database_connect_args` — never raw `DATABASE_URL`.
- Tests never touch Neon; they use in-memory async SQLite.
- `password_hash` must never appear in a response or log.
- Hashing: `pwdlib[argon2]`. Tokens: `PyJWT`, HS256, `sub` = `str(user.id)`.
- `SECRET_KEY` is required (no insecure default); `ACCESS_TOKEN_EXPIRE_MINUTES` defaults to `30`.
- All domain endpoints live under `/api/v1`; `GET /health` stays at the root.
- FastAPI dependency style: `Annotated[Type, Depends(...)]`, never `= Depends(...)`.
- Ruff: `line-length = 100`, `target-version = "py313"`; `uv run ruff check .` must stay clean.
- Do not commit `.env`.

## Review Focus

Input classes the spec implies but that no single endpoint test naturally pins. Each line names the behavior a reasonable person expects; the owning task adds the test that pins it.

1. **Email case-insensitivity.** `Signup("A@Example.com")` then `Login("a@example.com")` must work, and a second signup with a different case must 409 — not create a duplicate. (Task 3, Task 4)
2. **Long / non-ASCII passwords.** A 200-character unicode passphrase must hash and verify — argon2 has no bcrypt-style 72-byte truncation. (Task 2)
3. **Signed token with a bad `sub`.** A correctly-signed token whose `sub` is a non-UUID string or an unknown UUID must yield **401, never 500**. (Task 5)
4. **Malformed Authorization header.** A missing header, a non-`Bearer` scheme, or an empty token must yield **401, never 500**. (Task 5)
5. **Duplicate email at the database boundary.** The insert path must translate a unique-constraint violation into **409, never 500**. (Task 3)

```python
from datetime import datetime, timedelta, timezone

import jwt
from pwdlib import PasswordHash

from app.core.config import settings

ALGORITHM = "HS256"

_password_hash = PasswordHash.recommended()


def hash_password(password: str) -> str:
    return _password_hash.hash(password)


def verify_password(password: str, password_hash: str) -> bool:
    return _password_hash.verify(password, password_hash)


def create_access_token(subject: str, expires_delta: timedelta | None = None) -> str:
    now = datetime.now(timezone.utc)
    expires = now + (
        expires_delta or timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
    )
    payload = {"sub": subject, "iat": now, "exp": expires}
    return jwt.encode(payload, settings.SECRET_KEY, algorithm=ALGORITHM)


def decode_access_token(token: str) -> str | None:
    try:
        payload = jwt.decode(token, settings.SECRET_KEY, algorithms=[ALGORITHM])
    except jwt.InvalidTokenError:
        return None
    subject = payload.get("sub")
    return subject if isinstance(subject, str) else None
```

- [ ] **Step 4: Create the service**

Create `app/modules/auth/service.py`:

```python
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import AsyncSession

from app.modules.auth.security import hash_password
from app.modules.users.models import User


class EmailAlreadyExistsError(Exception):
    """Raised when creating a user whose email is already taken."""


def _normalize_email(email: str) -> str:
    return email.strip().lower()


async def get_user_by_email(session: AsyncSession, email: str) -> User | None:
    result = await session.execute(select(User).where(User.email == _normalize_email(email)))
    return result.scalar_one_or_none()


async def create_user(session: AsyncSession, email: str, password: str) -> User:
    user = User(email=_normalize_email(email), password_hash=hash_password(password))
    session.add(user)
    try:
        await session.commit()
    except IntegrityError as exc:
        await session.rollback()
        raise EmailAlreadyExistsError from exc
    await session.refresh(user)
    return user
```

The `IntegrityError` translation is what keeps a duplicate email a `409` (Task 3 Review Focus #5) rather than a `500`, even if two requests race.

- [ ] **Step 5: Create the auth router**

Create `app/modules/auth/router.py`:

```python
from typing import Annotated

from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.ext.asyncio import AsyncSession

from app.db.session import get_db
from app.modules.auth import service
from app.modules.auth.schemas import SignupRequest, SignupResponse
from app.modules.auth.security import create_access_token

router = APIRouter(prefix="/auth", tags=["auth"])


@router.post("/signup", status_code=201, response_model=SignupResponse)
async def signup(
    payload: SignupRequest,
    session: Annotated[AsyncSession, Depends(get_db)],
) -> SignupResponse:
    try:
        user = await service.create_user(session, str(payload.email), payload.password)
    except service.EmailAlreadyExistsError:
        raise HTTPException(status_code=409, detail="Email already registered") from None
    return SignupResponse(access_token=create_access_token(str(user.id)), user=user)
```

Create `app/modules/auth/deps.py`:

```python
import uuid
from typing import Annotated

from fastapi import Depends, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from sqlalchemy.ext.asyncio import AsyncSession

from app.db.session import get_db
from app.modules.auth.security import decode_access_token
from app.modules.users.models import User

bearer_scheme = HTTPBearer(auto_error=False)


async def get_current_user(
    credentials: Annotated[HTTPAuthorizationCredentials | None, Depends(bearer_scheme)],
    session: Annotated[AsyncSession, Depends(get_db)],
) -> User:
    if credentials is None:
        raise HTTPException(status_code=401, detail="Not authenticated")
    subject = decode_access_token(credentials.credentials)
    if subject is None:
        raise HTTPException(status_code=401, detail="Invalid or expired token")
    try:
        user_id = uuid.UUID(subject)
    except ValueError:
        raise HTTPException(status_code=401, detail="Invalid or expired token") from None
    user = await session.get(User, user_id)
    if user is None:
        raise HTTPException(status_code=401, detail="Invalid or expired token")
    return user
```

`HTTPBearer(auto_error=False)` makes a missing header return our `401` instead of FastAPI's default `403`, and the `uuid.UUID` guard keeps a bad `sub` a `401` (Task 5 Review Focus #3) rather than a `500`.
